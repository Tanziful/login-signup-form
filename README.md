# 🔐 Login/Signup Form (HTML + CSS + JavaScript)

A simple and clean login/signup form UI built with HTML, CSS, and JavaScript. This project includes basic front-end validation logic and user-friendly design.

---

## 🚀 Features

- 📄 Login and Signup forms side-by-side
- 🧠 JavaScript validation (email, password, username)
- 🎨 Clean and responsive design using CSS
- 🚫 Prevents form submission if input is invalid
- ✅ Alerts success or error messages

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
